# Fake News Verifier — Claude Autonomous Project Kit

This kit contains the project-level instructions, agents, skills, documentation, and master prompt for building the Fake News Verifier with Claude Code.

## Intended stack
- ASP.NET Core API
- React + TypeScript user app
- Vue 3 + TypeScript admin app
- Chart.js
- EF Core
- PostgreSQL or SQL Server
- Docker

## One-shot workflow

1. Copy this kit into your project root.
2. Review CLAUDE.md.
3. Review docs/credibility-scoring.md.
4. Initialize a git repository.
5. Ensure Claude Code is installed and authenticated.
6. Run Claude from the project root.
7. Paste or execute MASTER-PROMPT.md.

## Important
One-shot autonomous execution can create many files and consume significant model/tool usage. For a real repository, keep git commits/checkpoints so changes can be reviewed or reverted.

Never use an unsafe permission mode blindly on an important repository.
