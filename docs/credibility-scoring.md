# Credibility Scoring

Score range: 0–100.

Signals:
- source reliability
- evidence strength
- source independence
- cross-source agreement
- contradiction
- recency
- claim specificity

The scoring algorithm must be deterministic and versioned.

Suggested interpretation:
0–19 Extremely Low Evidence
20–39 Low Evidence
40–59 Uncertain
60–79 Relatively Supported
80–100 Strongly Supported

These labels describe available evidence, not objective truth.

Weights and formula must be finalized and implemented consistently before release.
