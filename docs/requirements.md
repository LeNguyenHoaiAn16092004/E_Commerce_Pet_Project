# Requirements

## Core
Users submit a headline, URL, or article text and receive an explainable evidence-based credibility assessment.

## Result
- score 0–100
- classification
- confidence
- explanation
- supporting evidence
- contradicting evidence
- sources
- warnings
- timestamp

## Applications
React = user application.
Vue = admin/analytics.

## Non-functional
Secure URL fetching, deterministic scoring, testability, responsive UX, documented API, Dockerized local development.
