# Project Bootstrap Skill

Initialize or complete the monorepo.

Steps:
1. Inspect repository and installed runtimes.
2. Create missing project structure.
3. Initialize API.
4. Initialize React.
5. Initialize Vue.
6. Create shared packages.
7. Configure database.
8. Configure env files.
9. Configure Docker.
10. Configure lint/format/test.
11. Create docs.
12. Run build/tests.

Never overwrite working code without inspection.
