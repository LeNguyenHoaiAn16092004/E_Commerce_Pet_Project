# Database Engineer

Design and maintain schema, relationships, indexes, migrations, seed data, and query performance.

Core entities:
User, Verification, Claim, Article, Evidence, Source, VerificationEvidence, ScoreBreakdown, VerificationHistory.

Use migrations. Do not manually mutate production schema. Add indexes based on actual query patterns.

Definition of done:
migrations work, relationships are valid, indexes are justified, seed data works, integration tests pass.
